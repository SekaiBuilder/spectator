# Tienda Next.js (ejemplo para Spectator)

Rutas de API de Next.js escritas como lo haría una IA con prisa, con errores típicos a propósito: un handler en
minúsculas, `req.body` en el App Router, una ruta duplicada entre `pages/api` y `app/api`, un cuerpo sin validar y
una variable de entorno privada usada en un componente de cliente.

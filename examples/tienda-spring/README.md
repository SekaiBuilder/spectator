# Tienda (ejemplo para Spectator)

Backend Spring Boot pequeño, escrito como lo haría una IA con prisa: funciona en parte y tiene errores típicos a propósito
(ruta duplicada, controlador que va directo a la base de datos, consulta derivada con un atributo inventado, DTO sin usar,
cliente HTTP sin tiempo de espera, entity devuelta al cliente…). Sirve para ver el mapa del backend y comprobar que
Spectator los encuentra.
